===============================================================
UrbanNest Interiors - Complete Website Project
Inspired by DesignCafe & Render.ai
===============================================================

HOW TO RUN:
1. Extract / Unzip this folder.
2. Double-click "index.html" (or "interior.html") to open the website in any web browser (Chrome, Edge, Safari, Firefox).
3. No installation, server, or Node.js required! Runs 100% locally.

PROJECT STRUCTURE:
- index.html (or interior.html) : Main entry webpage
- css/
    - interior.css             : Core styling, theme variables, 3D Wall Studio styles
    - main.css                 : Grid and helper utility classes
- js/
    - interior.js              : Interactive script for render.ai slider, 3D wall customizer,
                                 1BHK/2BHK cost estimator, theme switcher, and modals
- images/                      : High-resolution optimized project showcase and designer photos

KEY FEATURES INCLUDED:
1. Dark / Light Mode Switcher & 4 Brand Accent Palette Colors (in sidebar)
2. render.ai Before & After Slider (Black & White clay vs photorealistic color materials)
3. Interactive 3D Wall Studio (Custom wall paint, slats, brick, marble tiles, lighting & cost calc)
4. DesignCafe-Style Instant Cost Estimator (1 BHK / 2 BHK / 3 BHK / 4 BHK flat system)
5. Full Navbar Sections: Home, Showcase, 3D Render Switcher, 3D Wall Studio, Services,
   Cost Estimator, Designers, Packages (with EMI breakdown), Reviews & FAQ, Contact form.
